# Travelodge Golden - Property Map

Interactive 3D wayfinding map for Travelodge by Wyndham Denver Golden.
Guests enter a room number or tap an amenity and get a route with step-by-step directions.

Everything runs from the single file `index.html`. It needs no server or internet after loading.
